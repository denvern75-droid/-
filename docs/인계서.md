## 6. 소통 방식 (미해결 과제)
- 클라우드 Claude(claude.ai/code)는 Windows PC의 Hermes에 직접 접근할 수 없음. 원격 연결은 Mac·Linux만 지원함.
- 현재 방식: 사용자가 Hermes 화면을 캡처해 전달 → Claude가 다음에 입력할 문장을 제시함
- 개선안: Claude 데스크톱 앱의 Code 탭을 로컬로 실행하고, 폴더를 `C:\Users\Senseone`으로 선택한 뒤 `hermes/handoff-local-claude.md`를 붙여넣음 → 로컬 Claude가 Hermes를 직접 조작함
