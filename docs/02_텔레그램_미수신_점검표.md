# 텔레그램 미수신 — 계층별 점검표

> 위 계층이 실패하면 아래 계층은 점검할 필요 없음.
> 자동 점검: `python run_relay.py doctor --config config.json`

| 계층 | 증상 | 확인 방법 | 원인 | 조치 |
|---|---|---|---|---|
| 1. 실행 | 로그 파일이 아예 생성되지 않음 | `Get-ScheduledTaskInfo -TaskName 'HermesDailyReportRelay'` → `LastTaskResult` = `0x2`/`0x1` | **예약 작업 Python 경로 오류(이번 장애)** | `Repair-HermesTaskPython.ps1` |
| 1. 실행 | 작업이 실행되지 않음 | `LastRunTime` 이 과거에 멈춤 | 노트북 절전·종료 | `WakeToRun` + `StartWhenAvailable` 적용(교정 스크립트가 자동 설정함) |
| 1. 실행 | Store 창이 뜬 적 있음 | `where.exe python` 결과에 `WindowsApps` 포함 | Microsoft Store 스텁 | python.org 정식 설치본 사용 |
| 2. 설정 | `설정 오류` 로그 | `doctor` 2번 항목 | 토큰·chat_id 누락, 따옴표 혼입 | `config.json` 또는 환경변수 수정 |
| 2. 설정 | JSON 파싱 오류 | `doctor` 2번 항목 | 메모장 저장 시 BOM·인코딩 | 본 도구는 BOM을 허용함. 그 외 오류는 쉼표·따옴표 확인 |
| 3. 경로 | `감시 폴더 접근 불가` | `doctor` 3번 항목 | 매핑 드라이브(`Z:`)·환경변수(`%OneDrive%`) 사용 | **절대경로 또는 UNC 경로**로 변경 |
| 3. 경로 | `조건에 맞는 보고 파일 0건` | `doctor` 3번 항목 | 확장자 필터 불일치, 보고서 저장 위치 상이 | `extensions`·`watch_dirs` 조정 |
| 4. 권한 | 상태·로그 쓰기 불가 | `doctor` 4번 항목 | `Program Files` 등 보호 경로에 설치 | 사용자 쓰기 가능 경로로 이동 |
| 5. 망 | `api.telegram.org 연결 실패` | `doctor` 5번 항목 | 사내 방화벽·프록시 | `proxy_url` 설정 또는 방화벽 예외 신청 |
| 6. 인증 | `getMe 실패 401` | `doctor` 6번 항목 | 토큰 오타·재발급으로 무효화 | BotFather에서 토큰 재확인 |
| 7. 대화방 | `최근 대화 이력 없음` | `doctor` 7번 항목 | **봇에게 `/start` 를 보낸 적 없음** | 텔레그램에서 봇에게 `/start` 1회 발송 |
| 7. 대화방 | `403 bot was blocked` | 로그 | 사용자가 봇을 차단함 | 차단 해제 후 재시도 |
| 7. 대화방 | `400 chat not found` | 로그 | 그룹 → 슈퍼그룹 전환으로 ID 변경 | `-100...` 형태의 새 ID로 갱신 |
| 8. 전송 | 일부만 전송됨 | 로그 `실행 요약` | 첨부 50MB 초과 | 본문·경로만 전송됨(정상 동작). 원본은 공유 폴더에서 열람 |
| 8. 전송 | 같은 보고가 반복 전송됨 | 로그 | 원본 파일이 계속 수정됨 | 정상 동작. 수정본은 재전송 대상임 |
| 8. 전송 | 새 보고가 전송되지 않음 | 로그 `중복생략` | 이미 전송된 것으로 기록됨 | `--resend` 로 강제 재전송 |

## 무음 장애 판별

- 정상 상태에서는 **매일 09시 생존 신고**가 도착함
- 생존 신고가 끊긴 날 = 노트북 또는 예약 작업 장애로 판단함
- 생존 신고는 오는데 보고만 안 옴 = 감시 폴더(3계층) 또는 확장자 필터 문제임

## 자주 쓰는 명령

```powershell
# 최근 실행 결과
Get-ScheduledTaskInfo -TaskName 'HermesDailyReportRelay' | Select-Object LastRunTime, LastTaskResult, NextRunTime

# 등록된 실행 경로 확인
(Get-ScheduledTask -TaskName 'HermesDailyReportRelay').Actions | Format-List Execute, Arguments, WorkingDirectory

# 실제 Python 위치 확인(WindowsApps 가 나오면 스텁임)
where.exe python
py -3 -c "import sys; print(sys.executable)"

# 최근 로그 50줄
Get-Content .\logs\relay.log -Tail 50 -Encoding UTF8

# 강제 재전송
python .\run_relay.py once --config .\config.json --resend
```
