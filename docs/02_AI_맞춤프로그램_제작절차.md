# AI(Claude)로 내게 필요한 프로그램 만들기 — 표준 절차

- 작성일: 2026-10-14
- 목적: 유료·맥 전용 프로그램을 **업무 맞춤형 윈도우 프로그램으로 직접 재제작**하는 절차를 표준화함
- 적용 사례: 「텍스트 액션」(PopClip 재구성) — `textaction/`

---

## 1. 핵심 요약

- 기존 프로그램을 "그대로 복제"하지 않고 **내 업무에 필요한 기능만 골라 다시 만듦**
- 1개 프로그램 = **요청서 1장 → 시제품 → 시험 → 보정 → 배포** 5단계로 진행함
- 개발 지식 없이 Claude Code에 요청서만 전달하면 코드·빌드·설명서까지 산출됨

## 2. 5단계 절차

| 단계 | 내가 할 일 | Claude가 할 일 | 산출물 |
|---|---|---|---|
| ① 요청 | 아래 요청서 양식 작성 | 요구사항 정리·기능 범위 확정 | 기능 명세 |
| ② 시제품 | 확인만 함 | 코드 작성·자체 점검 | 실행 가능한 프로그램 |
| ③ 시험 | 실제 업무 문서로 5~10회 사용, 결과 기록 | — | 시험 결과표 |
| ④ 보정 | 불편 사항 전달 | 수정·재검증 | 개선본 |
| ⑤ 배포 | 설치 대상 PC 지정 | exe 빌드·설치 안내서 작성 | 설치파일 + 안내서 |

## 3. 요청서 양식 (복사해서 사용)

```
[프로그램 이름]
[참고 프로그램] 예: 맥 PopClip / 유료 앱 ○○ (없으면 생략)
[누가 쓰나] 예: 나 혼자 / 팀원 5명 / 참여자(시각장애인 포함)
[언제 쓰나] 예: 공문 작성 중, 근무기록부 수합 시
[해야 할 일] 1) … 2) … 3) …
[하면 안 되는 일] 예: 개인정보 외부 전송 금지, 원본 파일 수정 금지
[입력 → 출력] 예: 한글 문서 선택 문장 → 개조식 문장
[사용 환경] 예: 윈도우 11, 한글 2022, 센스리더 사용
[성공 기준] 예: 10건 중 8건 이상 수정 없이 사용 가능
```

## 4. 업무 맞춤 제작 후보 (우선순위)

| 순위 | 프로그램 | 참고 원본 | 해결 업무 | 상태 |
|---|---|---|---|---|
| 1 | 텍스트 액션 | PopClip(맥) | 개조식·윤문·이지리드·법령점검 | **시제품 완료** |
| 2 | 폴더 비서 | Hazel(맥) | 근무기록부·공문 수합 자동 분류·이름 정리 | 요청서 작성 대기 |
| 3 | 화면 글자 추출 | TextSniper(맥) | 스캔 공문·이미지 안내문 텍스트화 | 요청서 작성 대기 |
| 4 | 회의록 비서 | 유료 녹취·요약 앱 | 녹음 → 회의록(개조식) 자동 작성 | 요청서 작성 대기 |

## 5. 유의사항

- 유료 프로그램의 **코드·디자인·명칭을 복제하지 않음** — 기능 아이디어만 참고함 (저작권·상표 분쟁 예방)
- 개인정보가 포함된 문서는 외부 AI 전송 전 가리기(마스킹) 처리하거나 사용하지 않음
- AI가 만든 프로그램은 ③ 시험 단계를 반드시 거친 뒤 업무에 투입함
