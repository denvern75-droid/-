# 윈도우용 Claude 연계 업무도구 제작 기획서 (초안)

- 작성일: 2026-10-14
- 상태: 준비 단계(MVP 1종 코드 완료, 실사용 검증 전)

---

## 1. 핵심 요약

- 맥에만 있는 생산성 앱(PopClip·Hazel·TextSniper 등)의 기능을 **윈도우용 + Claude 연계**로 재구성함
- 1차 제품: **「텍스트 액션」** — 어느 프로그램에서든 글 선택 → 단축키 → 개조식·윤문·요약·이지리드·법령점검·대체텍스트 즉시 변환
- MVP 코드 작성 완료(`textaction/`), 윈도우 PC에서 API 키 입력 후 실사용 시험 필요함
- 유료화는 **사용자 본인 API 키 방식(BYOK) + 정액 라이선스**가 원가 리스크 최소안임
- 미확정 사항: 요청서의 "아래 링크"가 전달되지 않았고, "서울리아" 영상은 검색으로 특정되지 않음 → 링크 제공 시 후보 목록 재조정 필요함

## 2. 문제 진단

| 구분 | 현황 | 문제 |
|---|---|---|
| 문서 작업 | 한글·워드·메일에서 개조식 변환·윤문을 수작업 반복 | 건당 5~10분 소요, 품질 편차 발생 |
| AI 활용 | 웹 채팅창에 복사·붙여넣기 왕복 | 창 전환·프롬프트 재입력으로 흐름 단절 |
| 운영체제 | 기관 PC 대부분 윈도우 | 맥 전용 효율 앱(PopClip 등) 사용 불가 |
| 접근성 | 이지리드·대체텍스트 작성 수요 상존 | 전담 인력 부족, 작성 기준 불균일 |

## 3. 원인 분석

- 맥 생태계는 **"선택 → 즉시 동작"** 형태의 시스템 확장 앱이 발달함
- 윈도우는 동일 범주 앱이 적고, 있어도 **한국 공공문서 문체(~함/~임/~됨)** 를 지원하지 않음
- 범용 AI 채팅은 **업무 규칙(개조식·수치 보존·법령 확인 표시)** 을 매번 다시 지시해야 함

## 4. 맥 전용 앱 → 윈도우 재구성 후보

| 순위 | 맥 원본(기능) | 윈도우 재구성안 | 업무 적용 | 난이도 |
|---|---|---|---|---|
| **1** | PopClip (선택 텍스트 액션) | **텍스트 액션** — 단축키 메뉴 + Claude 변환 | 개조식·윤문·요약·이지리드 | 하 (**MVP 완료**) |
| 2 | Hazel (폴더 규칙 자동 정리) | **폴더 비서** — 감시 폴더에 파일 투입 시 분류·이름변경·요약 | 근무기록부·공문 수합본 자동 정리 | 중 |
| 3 | TextSniper (화면 OCR) | **화면 글자 추출** — 영역 캡처 → 텍스트화 → 액션 연결 | 스캔 공문·이미지 안내문 텍스트화(시각장애 접근성) | 중 |
| 4 | Keyboard Maestro (매크로) | **업무 매크로** — 반복 클릭·입력 자동화 | 보조금 시스템 반복 입력 | 상 (리스크 큼) |

- 2~3순위는 1순위 사용성 검증 후 착수함

## 5. 실행 전략 — Claude 연계 순차 작업

| 단계 | 작업 | 산출물 | 상태 |
|---|---|---|---|
| 1 | 대상 기능 선정·기획 | 본 기획서 | 완료 |
| 2 | MVP 코드 작성 | `textaction/` 패키지 | 완료 |
| 3 | 윈도우 PC 설치·시험 | 액션 6종 실사용 결과표 | **다음 단계** |

### 3단계 시험 절차 (윈도우 PC)

1. Python 3.11 이상 설치함
2. 명령 프롬프트에서 `pip install -r requirements.txt` 실행함
3. `setx ANTHROPIC_API_KEY "발급받은키"` 입력 후 명령 프롬프트 재실행함
4. `python -m textaction` 실행 → 한글 문서에서 문장 선택 → `Ctrl+Alt+Space`
5. 액션별 결과를 "그대로 사용 / 일부 수정 / 사용 불가" 3단계로 기록함

## 6. 비용 산정 (검증)

- 가정: 1회 입력 1,500토큰, 출력 800토큰, 1인 1일 30회, 월 22일 → **월 660회**
- 환율 1,400원/달러 가정(변동 시 재산정)

| 모델 | 단가(입력/출력, 100만 토큰당) | 1회 비용 | 월 비용(660회) | 원화 환산 |
|---|---|---|---|---|
| Opus 5.5 (기본값) | $4 / $20 | 0.006 + 0.016 = **$0.022** | **$14.52** | 약 20,300원 |
| Haiku 5.5 | $0.10 / $0.50 | 0.00015 + 0.0004 = **$0.00055** | **$0.36** | 약 510원 |

- 계산 검증: 1,500×4÷1,000,000=0.006 / 800×20÷1,000,000=0.016 / 0.022×660=14.52
- 모델은 환경변수 `TEXTACTION_MODEL`로 전환 가능함 → 시험 단계에서 두 모델 품질 비교 후 결정 권고함

## 7. 유료화 대안 (2~3안)

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A (권고)** | BYOK + 1회 구매 라이선스 | API 원가 부담 없음, 가격 단순 | 사용자가 API 키 발급해야 함 |
| B | 월 구독(API 비용 포함) | 설치 즉시 사용, 반복 수익 | 과다 사용 시 적자, 결제·서버 운영 필요 |
| C | 기관 단위 납품(커스텀 액션 포함) | 단가 높음, 기관 맞춤 | 영업·유지보수 부담 |
