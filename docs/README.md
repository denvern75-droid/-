# 길동무 — 집 → 새 사무실(금천구 독산로85길 37) 보행·환승 안내 (시험판)

## 1. 현재 판정 (2026-11-15)
- **시각장애인 이용자가 처음 가는 길에서 이 앱만 믿고 혼자 이동하는 용도로는 아직 적합하지 않음.**
- 근거: 실제 폰(GPS·나침반·TalkBack)과 실제 지도 데이터로 한 번도 시험하지 못했고, 독립 검증 3건(안전·접근성·종합 감사)이 모두 "아니오"로 판정했음. 이후 지적 사항을 수정했으나 수정본의 재검증과 현장 시험은 아직 없음.
- 쓸 수 있는 범위: 동행 또는 이동지원 서비스와 함께 쓰는 보조 도구, 그리고 현장에서 위치를 기록하는 도구.
- 흰지팡이·안내견·주변 소리 확인을 대체하지 않음.

## 2. 앱이 하는 일과 하지 못하는 일
| 구분 | 내용 |
|---|---|
| 함 | 목표 지점(출구·정류장·사무실)까지 **내 몸 기준 시계 방향과 직선거리**를 음성·진동으로 안내 |
| 함 | 지하철 역 세기(다음 버튼), 하차역 알림, 환승 방향 안내(다음 역 이름 기준) |
| 함 | 지나침 안내, 반대 방향 안내, GPS 끊김 알림, 진행 위치 저장(앱을 다시 열면 이어서 안내) |
| **못 함** | **길 모양·횡단보도·차도·일방통행·보차혼용을 모름.** 직선 방향만 알려 주므로 길과 횡단보도는 직접 확인해야 함 |
| 못 함 | 지하(역사 안)에서의 위치 안내, 실시간 버스 도착 정보(지도 앱 열기 버튼으로 대체) |
| 못 함 | 목적지 건물 입구·번지 확인(지도 좌표는 건물 중심이고 오차가 수십 미터일 수 있음) |

- `env.js`(횡단보도·점포·도로 정보 모델)는 **앱에 연결되어 있지 않음.** 믿을 만한 데이터 원천을 확보하지 못해 안내에 쓰지 않음.

## 3. 위치 정보의 출처와 신뢰도
| 출처 | 신뢰도 | 앱의 처리 |
|---|---|---|
| 현장에서 걸어서 기록(자동 기록·여기 저장) | 높음(여러 번 기록할수록 향상) | 정밀 안내, 도착·지나침·이탈 판정 사용 |
| 지도 데이터(OSM 자동 조회), 지도 앱 공유 | 낮음(오차 30~40m 이상 가능) | "대략 N미터"로만 안내, 30m 안에서 "부근임"을 알리고 계속 안내, 자동 도착·지나침·이탈 판정은 하지 않음 |
| 서울시 공식 정류소 위치 자료(2026-09-02 기준): 정류장 21002, 하차 정류장 | 중간(공식 좌표이나 현장 확인 전) | "대략 N미터"로 안내, 30m 안에서 "부근임" 안내 |
| OSM 주소 검색(번지·도로명 일치): 사무실 독산로85길 37 | 낮음~중간(건물 위치, 입구 아님) | 위와 같음 |
| 출처 불명: 금호역 1번 출구 좌표 | 확인 안 됨(주택가 도로 위 지점) | 낮음으로 처리 |

- 2026-11-15 실제 데이터 확인 결과는 `data/verified-points.json`에 출처와 함께 기록함.
- **정류장 21002와 하차 정류장은 도로 한가운데의 중앙차로 승강장임.** 횡단보도를 건너야 하며, 앱은 그 횡단보도 위치를 모름. 그래서 21002 정류장 60m 안에서는 방향 안내·비프음·도착 판정을 멈추고 "주변 사람에게 횡단보도를 물어보세요"라고 안내함. 같은 자리에 반대 방향 승강장(21001)이 붙어 있어 GPS로는 구분할 수 없으므로 방면 확인을 안내함.
- 확인되지 않은 좌표에서는 도착을 선언하지 않음. 저장된 위치에 왔음을 알리고, 이용자가 찾은 뒤 다음 버튼으로 진행함.
- 기존 "구로디지털단지역 6번 출구" 좌표는 역 승강장 중심으로 확인되어 목표에서 뺐음. 지상에 나온 위치에서 정류장으로 바로 안내함. **출구 좌표는 아직 확보하지 못함**(OSM 조회 서버 접속 실패).
- 사무실로 들어가는 골목은 **시흥대로138길**로 확인함(OSM 도로 형상). 큰길 모퉁이에서 사무실까지 약 210m이고 사무실은 골목 끝에서 23m. 모퉁이 좌표를 좌회전 지점으로 넣었음. 동료가 말한 서울정형외과의원 건물이 이 모퉁이에 있다는 것은 추정임.
- 하차 승강장은 남쪽 것(18002)으로 판단함. 승강장에서 모퉁이까지 약 140m + 골목 약 210m가 카카오맵 도보 380m와 맞고, 북쪽 승강장 기준(약 500m)과는 맞지 않음. 퇴근 승차 승강장은 북쪽 것(18001)으로 둠. 현장 확인 전임.
- 사무실 번지에는 OSM에 "강원도 올챙이국수" 음식점이 등록되어 있음(영업 여부 미확인). 도착 안내에서 알려 줌.
- 지도 데이터 자동 조회(`seed.js`)는 가상 응답으로만 시험했음. 실제 조회에서 역 이름을 검색하면 같은 이름의 버스 정류장이 먼저 나오는 것을 확인해 검색 개수를 늘렸으나, 출구 조회는 실데이터로 확인하지 못함.
- 자동 조회 규칙: 출구는 번호 일치(다른 역 이름 제외, 반경 200m), 정류장은 번호 일치만, 주소는 번지와 도로명이 일치할 때만 채움. 애매하면 채우지 않음.

## 4-2. 혼자 처음 갈 때의 자동 기록
- [안내 시작]을 누르면 **이동 기록이 자동으로 함께 저장됨**(별도 조작 없음). 3초마다의 위치 궤적과, 구간 전환·역 세기·확인 시점을 폰에 저장함. 최근 6회분 보관.
- 다음 버튼으로 확인한 순간의 위치를 확인된 좌표로 저장함: 정류장·사무실을 "찾았음", 길을 "건넜음", 버스에서 "내렸음". 다음 이동부터는 그 좌표로 더 정밀하게 안내함. 기존 위치와 60~80m 넘게 다르면 반영하지 않고 보류함.
- 편도만 기록되어도 됨. 출근(봉천역 출발)과 퇴근(여의도 경유)은 따로 쌓이며, 하차 승강장·건넌 지점·사무실 위치는 한쪽 기록만으로도 채워짐.
- [이동 기록 보내기]로 기록 파일을 공유할 수 있음. 이 파일이 있으면 꺾는 지점과 횡단 위치를 분석해 경로에 반영할 수 있음.
- 경로 "봉천역 출발": 2호선 봉천 → 구로디지털단지(세 번째 역, 다음 역이 신림역인 열차) → 6번 출구 → 중앙차로 정류장 21002 → 버스 한 정류장 → 문성초등학교 → 사무실.

## 4-3. 버튼 없이 자동 진행 (기본 켜짐)
- 출발 전에 [안내 시작]을 한 번 누르면, 이동 중에는 버튼을 누르지 않아도 단계가 넘어감. 설정의 "버튼 없이 자동 진행"으로 끌 수 있음. 이 모드에서는 버튼을 누르라는 안내 문장을 말하지 않음.

| 전환 | 자동 판단 기준 (4차 검증 반영) | 틀릴 수 있는 경우 |
|---|---|---|
| 걷기 → 지하철 | 구간 시작 2분 뒤, 걷다가 GPS가 20초 넘게 끊김 | 건물 안에서 GPS가 끊기면 일찍 넘어감 |
| 지하철 하차 예고 | **시간 기준**(구간 예상 시간의 80%) | 열차를 오래 기다리면 일찍 나옴. 역 이름은 안내방송으로 확인해야 함 |
| 지하 환승 구간 | 시간 기준으로 다음 안내로 넘어감. **퇴근 마지막 구간(신금호역에서 집까지)은 시간으로 넘어가지 않고 지상 위치로만** | 실제 진행과 어긋날 수 있음 |
| 지하철 → 걷기 | 1분 넘게 위치가 없다가, ① 걷는 속도 8회 + 실제 30m 이동 또는 ② 오차 20m 이내 위치 10회. 최근 90초 안 차량·열차 속도가 있으면 보류. 다음 지점 450m 안 | 다른 역에서 나오면 "내린 역 확인"을 알림(구간 예상 시간 60% 전에는 알리지 않음) |
| 걷기 → 버스 | 정류장 80m 안에 온 적이 있고 차량 속도(초속 3.5m 초과)가 10초 | 정류장 앞에서 택시·다른 버스를 타도 같은 판단 |
| 버스 → 걷기 | 하차 승강장 **60m 안**에서 느린 속도가 **20초** | 승강장 앞 정차를 내린 것으로 볼 수 있음. 5분 안에 다시 달리면 버스 구간으로 돌아가며 이미 한 하차 예고는 되풀이하지 않음 |
| 길 건넘 | 도로 중심선(정류장 18001→18002→횡단보도→모퉁이 어림)에서 **건너야 할 쪽(왼쪽·동쪽)으로 18m 이상**, 오차 15m 이내 위치 **3회 연속** | 승강장을 따라 걷는 것은 건넘으로 세지 않음. 반대쪽(서쪽) 인도로 가면 한 번 알림. 도로 중심선은 지도 어림이라 현장 확인 전 |
| 목적지 | 확인 안 된 좌표 40m 안에 1분 머물면 안내 종료 | 건물 확인은 주변 사람에게 |

- 확인되지 않은 좌회전 지점은 미리 "꺾기"를 예고하지 않음. 25m 안에 오면 "이 근처"로만 알리고, 25m 안에 오지 않고 멀어지면 "지나쳤을 수 있음, 시흥대로138길을 물어보세요"를 한 번 알림.
- 북쪽 승강장(18001)에 내린 것으로 보이면 그쪽 횡단보도(뒤쪽 약 25m, 자료상 음향신호기)를 안내함.
- 화면이 10초 넘게 꺼졌다 켜지면 "안내가 멈췄었음"을 알리고 현재 위치로 다시 안내함.
- 자동 판단마다 이유(거리·속도·시간)를 이동 기록에 남김. 경로가 바뀌거나 2시간이 지나면 새 기록으로 저장함. 경로 목록의 첫 번째는 봉천역 출발(B), 두 번째는 퇴근(R)임.

- 지하에서는 위치를 알 수 없어 **역을 셀 수 없음.** 하차역은 시간으로 어림해 알릴 뿐이므로 안내방송이 기준임.
- 폰 화면이 꺼지거나 다른 앱으로 넘어가면 브라우저가 위치 수신과 음성을 멈출 수 있음. 이동 중에는 화면을 켠 채로 두어야 하며, 이 제약은 웹앱의 한계임.

## 5. 사용법
- 구간에 들어설 때는 핵심 두 문장만 말함(하차 직후 긴 낭독이 주변 소리를 가리지 않게). 전체 길 설명은 [구간 설명 듣기] 버튼으로 들음.
- [안내 시작] → 안내에 따라 이동. 안내 영역 아래의 버튼: 다시 듣기 / 구간 설명 듣기 / 다음(역·지점 확인) / 이전 단계 / 단계 건너뛰기 / 내 위치 보내기 / 음성 명령.
- 다음 버튼: 지하철에서는 역 세기(잘못 누르면 이전 단계 버튼으로 한 역 되돌림), 버스에서는 하차 후, 도보에서는 지점을 찾았을 때. 안내 중인 도보 지점을 건너뛰거나 이전·건너뛰기를 누르면 한 번 더 눌러 확인함.
- 시계 방향: 12시 정면, 3시 오른쪽, 6시 뒤돌아 유턴, 9시 왼쪽.
- 진동: 정방향 1회, 왼쪽 짧게 2회, 오른쪽 짧게 3회, 유턴 길게 3회, 도착 길게 1회, 경고 아주 짧게 여러 번.
- 화면낭독기(TalkBack)를 함께 쓰면 화면 위쪽의 "앱 음성 안내"를 끌 것(겹쳐 읽힘 방지).
- 지도 앱 열기: 카카오맵·네이버지도·구글지도를 사무실 목적지로 엶. 다녀와도 진행 위치는 저장됨.
- 현장 기록(접힌 메뉴): 걸으며 자동 기록, 지점에서 여기 저장, 지도 앱 공유로 받기. 기존 위치와 60~80m 넘게 다른 기록은 반영하지 않고 보류함.

## 6. 설치
- HTTPS 주소가 필요함. GitHub Pages: 저장소 Settings → Pages → 브랜치 `claude/home-office-voice-navigation-w54zcy`, 폴더 `/docs`. 안드로이드 크롬에서 열어 홈 화면에 추가.
- 이 설정은 아직 되어 있는지 확인하지 못했음.

## 7. 구성과 시험
| 파일 | 역할 |
|---|---|
| `engine.js` | 방향·거리 안내, 도착·지나침·이탈 판정, 칼만 필터, 측정 융합, 낭독용 문장 정리 |
| `app.js`, `index.html` | 화면, 음성(우선순위 큐), 진동, GPS·나침반, 기록, 진행 저장 |
| `learn.js` | 걸으며 자동 기록(집·출구·정류장·하차·사무실, 꺾는 곳) |
| `seed.js` | 지도 데이터(OSM) 자동 조회 |
| `links.js` | 지도 앱 열기, 공유 받은 위치 해석 |
| `env.js` | 보행 환경 정보 모델(**미연결**) |
| `tools/check-route.js` | 경로 좌표 검증 |

- 시험: `node --test docs/test/*.test.js` (91건 통과). **합성 좌표와 가상 응답에 대한 시험이며 현장 안전의 근거가 아님.**
