# 세컨드브레인 운영 가이드

## 1. 도입 절차 (3주)

| 주차 | 작업 | 완료 기준 |
|---|---|---|
| 1주차 1일 | 볼트 골격 복사: `vault-skeleton/` → 구글드라이브 `SecondBrain` | Obsidian에서 볼트가 열리고 Drive 동기화 아이콘이 정상 |
| 1주차 1일 | Hermes 설정에 vault MCP 연결 (`hermes/config.example.yaml`) | Hermes가 `_templates/daily.md` 내용을 읽어서 답함 |
| 1주차 1일 | 상시 지침 등록 (`hermes/standing-instructions.md`) | 텔레그램 메모 1건이 `00_Inbox`에 저장되고 "저장됨" 회신이 옴 |
| 1주차 2일 | 네이버·다음 자동전달 + Gmail 필터 | 테스트 메일 2건이 라벨과 함께 Gmail에 도착 |
| 1주차 2일 | 예약 작업 ①②⑥ 등록 | `hermes cron list`에 3건 표시 |
| 2주차 | 1주 점검 후 ③④ 등록 | 점검표 기준 충족 |
| 3주차 | ⑤⑦⑧ 등록 | 점검표 기준 충족 |

## 2. 노트북 운영 조건
- 평일 08:30~18:30은 절전 진입 금지로 설정함 (Windows: 전원 및 절전 → 화면 끄기만 허용, 절전 '안 함')
- 노트북 덮개를 닫을 때의 동작을 '아무것도 안 함'으로 설정함 (전원 연결 시)
- Hermes 게이트웨이를 로그인 시 자동 시작하도록 등록함
- 퇴근 후·주말에는 실행이 멈추는 것을 전제로 함 → 월요일 아침 브리핑에 "주말 누락분 포함"으로 처리함

## 3. 리스크 대응표

| 리스크 | 발생 신호 | 대응 |
|---|---|---|
| 민감정보 유출 | 알림·Inbox에 실명·장애 유형 노출 | 상시 지침 2번 재확인, 해당 노트 `_private`로 이동, 원인 프롬프트 수정 |
| 동기화 충돌 | Drive에 `(1)` 붙은 사본 파일 생성 | 자동화 쓰기 폴더를 00_Inbox·90_Daily로 제한 유지, 같은 노트를 동시에 편집하지 않음 |
| 예약 작업 누락 | 브리핑이 오지 않음 | `hermes cron list`로 게이트웨이 상태 확인, 절전 설정 확인 |
| 알림 피로 | 카카오·텔레그램 알림을 무시하게 됨 | 카카오 1일 3건 상한 유지, 텔레그램은 정해진 시간에 묶어서 발송 |
| 오분류·오적재 | Inbox에 광고·무관 메일 증가 | Gmail F3·F5 필터 범위 축소 |
| 잘못된 자동 수정 | 노트 내용이 의도와 다르게 바뀜 | 수정·이동은 텔레그램 승인을 거치게 하고, Drive 버전 기록으로 복원함 |

## 5. 클라우드 세션(Claude) 연계
- Claude 세션은 Google Drive 커넥터로 `SecondBrain` 폴더를 읽을 수 있음
- 활용 예:
  - "SecondBrain 90_Daily 이번 달 노트 기준으로 월간 실적 보고서 작성"
  - "20_섭외원장 기준으로 토론회 섭외 현황 점검"
  - "01_투입함 체크리스트로 총평보고서 생성"
- `_private` 폴더는 Claude 세션에도 열람을 요청하지 않는 것을 원칙으로 함
