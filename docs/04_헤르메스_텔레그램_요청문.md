# 사무실 노트북 헤르메스(Hermes Agent) — 텔레그램 요청 설정·요청문

- 목적: 사무실 노트북의 Hermes Agent에 텔레그램으로 작업을 지시함
  - 유튜브 자막 추출·분석 (클라우드 환경에서는 유튜브 차단으로 불가했던 작업)
  - 「텍스트 액션」 윈도우 실기 시험
- 근거: Hermes Agent 공식 문서(Telegram·Windows WSL2 안내) 및 공개 설치 가이드
- 주의: 공식 문서 원문을 이 환경에서 직접 열람하지 못함 → 명령어는 노트북에서 `hermes --help`로 최종 확인 필요함

---

## 1. 텔레그램 연결 설정 (최초 1회, 노트북에서)

| 단계 | 할 일 | 비고 |
|---|---|---|
| 1 | 텔레그램에서 **@BotFather** 대화 → `/newbot` → 봇 이름 입력 | 봇 토큰(긴 문자열) 발급됨 — 외부 공유 금지 |
| 2 | 텔레그램에서 **@userinfobot** 대화 → 내 숫자 ID 확인 | 예: 123456789 |
| 3 | 노트북 터미널(WSL2 또는 PowerShell)에서 `hermes gateway setup` 실행 → Telegram 선택 | 토큰·허용 사용자 ID 입력 |
| 4 | `hermes gateway run` 실행 (상주) | 노트북 절전 해제 필요 |
| 5 | 내 봇에게 `안녕` 전송 → 응답 확인 | 응답 없으면 4단계 창 오류 확인 |

### 3단계를 수동으로 할 경우 (`~/.hermes/.env` 파일)

```env
TELEGRAM_BOT_TOKEN=여기에_봇토큰
TELEGRAM_ALLOWED_USERS=여기에_내_숫자ID
```

- `TELEGRAM_ALLOWED_USERS`는 **반드시 본인 ID만** 입력함 — 비우면 타인이 노트북에 명령할 위험 있음

## 2. 텔레그램 요청문 (순서대로 1건씩 전송)

> 텔레그램 1회 메시지는 4,096자 제한이 있어 요청을 4건으로 나눔. 앞 요청 완료 보고를 받은 뒤 다음 요청을 보냄.

### 요청 ① 작업 환경 점검

```
[작업 지시 1/4] 작업 환경 점검

다음을 확인하고 결과만 개조식으로 보고해줘. 아무것도 설치·삭제하지 말 것.
1. 운영체제와 버전(Windows/WSL2 여부)
2. python, pip, git 설치 여부와 버전
3. yt-dlp 설치 여부
4. 인터넷으로 youtube.com 접속 가능 여부
5. 작업 폴더로 쓸 경로 제안 (예: 문서\hermes-work)

보고 형식: 항목 | 결과 | 조치 필요 여부
```

### 요청 ② 유튜브 자막 추출·분석

```
[작업 지시 2/4] 유튜브 영상 자막 추출·분석

대상 영상
- A: https://youtu.be/HX96Uqq7AMg  (AI로 내게 필요한 프로그램 다시 만들기)
- B: (서울리안 채널 맥 무료 프로그램 소개 영상 링크)

절차
1. yt-dlp가 없으면 설치 전에 나에게 먼저 물어볼 것
2. 각 영상의 한국어 자막만 내려받을 것 (영상 파일은 내려받지 말 것)
   예: yt-dlp --skip-download --write-auto-subs --sub-langs ko --convert-subs srt <링크>
3. 자막 파일을 작업 폴더에 저장하고 파일명을 알려줄 것
4. 자막 내용만 근거로 아래 형식으로 정리할 것. 자막에 없는 내용은 추측하지 말고 "확인 불가"로 적을 것

보고 형식 (한국어 개조식, ~함/~임/~됨)
1) 영상별 제목·채널·게시일·길이
2) 영상 A: 사용 AI 도구, 제작 절차(단계별), 사용한 프롬프트 원문, 다시 만든 프로그램 목록, 주의사항
3) 영상 B: 표 | 프로그램명 | 기능 | 윈도우판 여부 | 윈도우 대체 | 타임스탬프 |
4) 업무 적용 후보 3개 (장애인복지 기관 사무직·윈도우·한글/엑셀 업무 기준)
```

### 요청 ③ 「텍스트 액션」 윈도우 실기 시험

```
[작업 지시 3/4] 텍스트 액션 프로그램 시험

1. 작업 폴더에 GitHub 저장소 denvern75-droid/- 의 ccr-a74d2793-s4h11s 브랜치를 내려받을 것
   (비공개 저장소라 접근이 안 되면 멈추고 나에게 알릴 것)
2. pip install -r requirements.txt 실행 전 설치 목록을 먼저 보여주고 내 승인을 받을 것
3. API 키는 내가 직접 입력할 테니 키를 요구하는 단계에서 멈출 것
4. 키 입력 후 아래 명령으로 6개 액션을 각 1회씩 시험할 것
   python -m textaction --action gaejosik --text "검토 결과 특별한 문제는 없는 것으로 판단되며 추후 보완이 필요합니다."
   (yunmun, summary, easyread, lawcheck, alttext 도 같은 문장으로 시험)
5. 결과를 표로 보고: 액션 | 성공 여부 | 결과 요약 | 소요 시간 | 오류 내용
6. 개인정보가 포함된 실제 문서는 시험에 사용하지 말 것
```

### 요청 ④ 결과 묶음 전달

```
[작업 지시 4/4] 결과 정리

1. 요청 2·3의 결과를 하나의 Markdown 파일(작업결과_날짜.md)로 저장할 것
2. 파일 내용을 텔레그램으로 그대로 보내줄 것 (길면 나눠서 전송)
3. 작업 중 설치한 프로그램 목록과 생성한 파일 목록을 마지막에 적을 것
```

## 3. 리스크 및 운영 수칙

| 리스크 | 내용 | 대응 |
|---|---|---|
| 원격 명령 실행 | 텔레그램 메시지로 노트북에서 명령이 실행됨 | 허용 사용자 = 본인 ID 1개만, 봇 토큰 외부 공유 금지 |
| 기관 보안 | 기관 노트북에 외부 에이전트 상주 시 보안 규정 위반 소지 | 전산 담당자 사전 확인 후 운영 |
| 개인정보 | 참여자 자료가 외부 AI로 전송될 수 있음 | 요청문에 "개인정보 문서 사용 금지" 명시, 업무 폴더 접근 제한 |
| 무단 설치 | 에이전트가 임의로 프로그램 설치 | 모든 요청문에 "설치 전 승인" 조건 명시 |
| 노트북 절전 | 절전·종료 시 응답 없음 | 작업 시간대만 상주, 종료 시 `Ctrl+C`로 게이트웨이 중지 |
