지도 앱에서 대중교통 보기

실시간 버스 도착과 환승 정보는 지도 앱에서 확인함. 목적지는 사무실로 자동 입력됨. 지도 앱을 다녀와도 안내 진행 위치는 저장되어 이어서 안내함.

공유로 받은 위치

현장 기록과 지도 데이터

지도 데이터는 앱을 열 때 자동으로 가져옴. 지점에 서서 저장하거나 걸으며 자동 기록하면 더 정확해짐. 지도 기준 위치는 오차가 있을 수 있음.

자동 기록: 평소처럼 걸으면 집, 출구, 정류장, 하차 지점, 사무실 위치와 걸은 방향과 거리가 저장됨.

설정

진동 규칙. 정방향은 1회, 왼쪽은 짧게 2회, 오른쪽은 짧게 3회, 유턴은 길게 3회, 도착은 길게 1회, 경고는 아주 짧게 여러 번.

사용 방법
  1. 출구에서 나오면 멈춰서 5초에서 10초 기다림. GPS가 잡히면 정류장까지 몇 미터, 몇 시 방향인지 내 몸 기준으로 알려줌.
  2. 12시는 정면, 3시는 오른쪽, 6시는 뒤돌아서 유턴, 9시는 왼쪽, 7시는 왼쪽 뒤임.
  3. 폰은 화면이 위로 가게 수평으로 들거나 가슴 앞에 세워 듦. 걷기 시작하면 걷는 방향으로 자동 보정됨.
  4. 지하철 안은 GPS가 안 됨. 역에 설 때마다 다음 버튼을 눌러 남은 역 수를 확인함.
  5. 버스에서 내린 뒤에는 멈춰 서서 다시 듣기를 누름.
