길동무 · 집→새 사무실 보행 안내

안전 안내: 흰지팡이·안내견·주변 소리 확인을 대체하지 않는 보조 도구임. GPS는 건물 사이에서 5~20m 오차가 날 수 있음. 횡단·계단·승강장에서는 반드시 직접 확인할 것.
안내 시작 버튼을 눌러주세요.

평소처럼 걸으면 집·출구·정류장·하차 지점·사무실 위치와 걸은 방향·거리가 자동으로 저장됨. 별도 조작 불필요.

지점에 실제로 서서 [여기 저장]을 누르면 약 8초간 GPS를 평균 내어 좌표로 저장함. 출구 바로 앞·정류장 기둥 옆·사무실 입구에서 저장할 것. 걸어오며 횡단보도·꺾는 지점도 [지점 추가]로 넣을 수 있음.

설정

진동 규칙: 정방향 = 짧게 1회 · 왼쪽 = 짧게 3회 · 오른쪽 = 짧게 5회 · 유턴 = 길게 3회 · 도착 = 길게 1회 · 경고 = 짧게 3회(강)

사용 방법
  1. 출구에서 나오면 멈춰서 5~10초 대기. GPS가 잡히면 "정류장까지 N미터, 7시 방향"처럼 내 몸 기준 시계 방향으로 알려줌.
  2. 7시 = 왼쪽 뒤, 6시 = 뒤돌아서 유턴, 3시 = 오른쪽 직각, 12시 = 정면.
  3. 폰은 화면이 위로 가게 수평으로 들거나 가슴 앞에 세워 들기. 걷기 시작하면 걷는 방향(GPS)으로 자동 보정됨.
  4. 지하철 안은 GPS 불가 → [다음]을 역에 설 때마다 눌러 남은 역 수 확인.
  5. 버스 하차 후에는 하차 즉시 멈춰 서서 [다시 듣기].
