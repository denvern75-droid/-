# 그록(Grok) 영상 분석 요청 프롬프트

- 용도: 유튜브 영상 2편의 내용을 그록으로 추출한 뒤 Claude에 붙여넣어 프로그램 제작에 활용함
- 사용법: 아래 [프롬프트 1] 또는 [프롬프트 2]를 그록에 그대로 붙여넣음 → 그록 답변 전체를 복사해 Claude에 전달함

---

## [프롬프트 1] 두 영상 통합 분석 (권고)

```
아래 유튜브 영상 2편을 분석해줘.

[영상 A] AI로 내게 필요한 프로그램을 다시 만드는 방법
https://youtu.be/HX96Uqq7AMg

[영상 B] 서울리안(Seoulian) 채널 — 맥 무료 프로그램 소개 영상
링크: (여기에 서울리안 영상 링크 붙여넣기)

[작업 규칙]
- 영상을 직접 확인할 수 없으면 "확인 불가"라고 먼저 밝히고, 추측으로 채우지 말 것
- 영상에서 실제로 언급된 내용만 적고, 내 의견은 [의견] 표시로 구분할 것
- 프로그램 이름은 영상에 나온 정확한 철자로 적을 것
- 한국어, 개조식(~함/~임/~됨)으로 작성할 것

[출력 형식]

1. 영상 기본정보
| 구분 | 제목 | 채널 | 게시일 | 길이 |

2. 영상 A — AI 프로그램 제작 방법
- 사용한 AI 도구(예: Claude, ChatGPT, Cursor 등)와 요금제
- 제작 절차를 단계별로(1단계, 2단계 …)
- 영상에서 실제로 사용한 프롬프트·명령어 문구(원문 그대로)
- 다시 만든 프로그램 목록과 원래 프로그램 이름
- 영상에서 언급한 주의사항·한계

3. 영상 B — 소개된 맥 무료 프로그램
| 번호 | 프로그램명 | 주요 기능(1줄) | 윈도우판 존재 여부 | 윈도우 대체 프로그램 | 영상 타임스탬프 |

4. 업무 적용 후보 (장애인복지 기관 사무직, 윈도우 PC, 한글·엑셀 위주 업무 기준)
| 순위 | 원본 프로그램 | 윈도우용으로 다시 만들 기능 | 활용 업무 예시 | 제작 난이도(상·중·하) |
- 3개 이내로 추천하고 추천 이유를 1줄씩 적을 것

5. 확인되지 않은 항목
- 영상에서 확인하지 못한 부분을 목록으로 적을 것
```

## [프롬프트 2] 영상 1편씩 간단 분석 (그록이 2편을 한 번에 못 볼 때)

```
다음 유튜브 영상의 내용을 정리해줘: (영상 링크)

- 영상을 직접 확인할 수 없으면 "확인 불가"라고 밝히고 추측하지 말 것
- 아래 4가지만 한국어 개조식으로 적을 것
  1) 제목·채널·게시일
  2) 핵심 내용 5줄 요약
  3) 언급된 프로그램·AI 도구 이름 전체 목록(정확한 철자, 타임스탬프 포함)
  4) 영상에서 보여준 절차·프롬프트 원문
```

## 그록 답변 받은 뒤 Claude에 붙여넣을 문구

```
아래는 그록이 정리한 영상 분석 결과임.
이 내용을 근거로 docs/02 절차서의 "업무 맞춤 제작 후보" 표를 갱신하고,
2호 프로그램 요청서를 작성한 뒤 시제품까지 만들어줘.

(그록 답변 전체 붙여넣기)
```

## 유의사항

- 그록도 영상을 직접 보지 못하고 제목·설명만으로 추측할 수 있음 → "확인 불가" 표시가 있는 항목은 사용하지 않음
- 프로그램 이름·기능은 Claude가 공식 사이트로 한 번 더 확인한 뒤 반영함

## [제미나이용] 유튜브 직접 분석 (그록보다 권고)

- 제미나이는 유튜브와 연동되어 있어 링크만 넣으면 영상 자막·내용을 직접 읽을 수 있음
- 위 [프롬프트 1]을 그대로 써도 되고, 아래 문구를 앞에 추가하면 정확도가 높아짐

```
@YouTube 아래 영상의 자막(스크립트)을 기준으로 분석해줘.
영상 자막을 불러올 수 없으면 "자막 확인 불가"라고 먼저 밝힐 것.
```

- 연동이 안 될 때: 제미나이 설정 → 앱(확장 프로그램) → YouTube 켜기
