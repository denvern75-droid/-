# Gmail 라벨·필터 규칙표

## 1. 라벨 체계

| 라벨 | 용도 | 부여 주체 |
|---|---|---|
| `출처/네이버` | 네이버에서 자동전달된 메일 | Gmail 필터 |
| `출처/다음` | 다음(한메일)에서 자동전달된 메일 | Gmail 필터 |
| `브레인` | 세컨드브레인 적재 대상 | Gmail 필터 + 수동 |
| `브레인/적재완료` | Hermes가 노트로 적재 완료 | Hermes |
| `긴급후보` | 공문·회신 요청 등 긴급 알림 점검 대상 | Gmail 필터 |

## 2. 필터 규칙

> Gmail → 설정 → 필터 및 차단된 주소 → 새 필터 만들기. 아래 검색어를 '검색어 포함' 칸에 입력함.
> `<네이버아이디>` 등은 실제 주소로 치환함.

| No | 검색어 | 동작 |
|---|---|---|
| F1 | `to:(<네이버아이디>@naver.com)` | 라벨 `출처/네이버` 적용 |
| F2 | `to:(<다음아이디>@daum.net OR <다음아이디>@hanmail.net)` | 라벨 `출처/다음` 적용 |
| F3 | `from:(*.go.kr OR *.or.kr) -category:promotions` | 라벨 `브레인` 적용 |
| F4 | `subject:(공문 OR 협조 OR "회신 요청" OR 제출 OR 마감)` | 라벨 `브레인`, `긴급후보` 적용 |
| F5 | `from:(<핵심 협력기관 주소 목록>)` | 라벨 `브레인` 적용 |
| F6 | `category:promotions OR unsubscribe` | 라벨 `브레인` 적용 안 함(필터 미설정) |

### 적용 원칙
- 필터에서 **'받은편지함 건너뛰기'와 '삭제'는 선택하지 않음** → 원본 흐름 유지
- F3·F5 기관 목록은 1주 운영 후 오적재 비율을 보고 조정함
- 개인정보가 많은 발신처(예: 참여자 개인 메일)는 `브레인` 필터에서 제외함

## 3. 수동 적재
- 필터에 걸리지 않은 메일은 직접 `브레인` 라벨을 붙이면 다음 적재 주기(12:00/17:00)에 처리됨
- 모바일 Gmail 앱에서도 라벨을 붙일 수 있음
