# 영상 오디오 분석 → Claude 활용 개선 워크플로우

## 1. 핵심 요약
- 대상 영상: https://youtu.be/Lrh-elQaS4c (내용 미확인 상태)
- 상태: 클라우드 세션 네트워크 정책으로 `www.youtube.com` 접속 차단 → 자막·음성 확보 불가
- 확인 결과(2026-10-29 기준)
  - 보유 스킬 중 영상 자막 추출용 스킬 없음 (shorts-* 계열은 영상 '제작'용)
  - Descript: YouTube URL 직접 가져오기 거부됨 (HTML 페이지로 인식)
  - 커넥터 레지스트리: 회의록용(Fireflies·tl;dv 등)만 확인, YouTube 자막용은 확인되지 않음
- 조치: 영상 확보 경로 4종과 분석 틀을 선(先)구축함. 영상 본문 확보 즉시 분석 가능

## 2. 영상 확보 경로 (우선순위순)
| 순위 | 경로 | 방법 | 비고 |
|---|---|---|---|
| 1 | 자막 텍스트 붙여넣기 | 유튜브 "더보기 → 스크립트 표시" 전체 복사 후 대화창에 붙여넣기 | 가장 빠름, 설정 변경 불필요 |
| 2 | 도메인 허용 | 환경 메뉴 → Edit → Network access에서 `www.youtube.com`(및 `youtu.be`) 허용 | 허용 후 자막 추출 재시도, 미검증 |
| 3 | 로컬 PC 추출 | PC에서 `yt-dlp --write-auto-subs --sub-langs ko --skip-download <URL>` 실행 후 .vtt 업로드 | 미검증, PC 설치 필요 |
| 4 | 음성 파일 전사 | mp3·mp4 업로드 → ElevenLabs 전사 또는 Descript 업로드 후 transcript 추출 | 소요 시간 최장 |

## 3. 분석 절차 (자막 확보 후)
1. 구조 파악: 전체 흐름, 화자, 구간별 주제(타임코드 포함)
2. 핵심 주장·도구·방법 추출(원문 근거 병기)
3. 현재 환경 대비 갭 분석
   - 현재: Claude Code, 업무 스킬, Drive·Gmail·Calendar 연동
4. 즉시 적용안 2~3개 (CLAUDE.md 규칙, 스킬, 프롬프트 템플릿)
5. 리스크 점검: 개인정보, 수치 오류, 법령 근거, 자막 오인식
