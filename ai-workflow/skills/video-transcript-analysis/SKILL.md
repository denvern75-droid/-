# 영상 대화 분석 스킬

## 원칙
- 영상 본문을 확보하지 못하면 내용을 추정해 작성하지 않음. 확보 실패 사유와 대안을 먼저 보고함
- 수치·고유명사·도구명은 자막 원문과 대조 후 기재함
- 문체: 개조식, "~함/~임/~됨" 종결

## 1단계 본문 확보 (순서대로 시도, 실패 시 다음 단계)
1. 사용자가 붙여넣은 자막·대본이 있으면 그대로 사용함
2. 자막 추출 시도: `yt-dlp --write-auto-subs --sub-langs ko,en --skip-download <URL>` 실행 후 .vtt 정리
3. 네트워크 차단 시 중단하고 안내함: 차단 호스트명 명시, 환경 설정의 Network access에서 허용 요청
4. 사용자 제공 음성·영상 파일은 전사 도구(ElevenLabs 전사, Descript)로 텍스트화함
- 주의: Descript는 YouTube URL을 직접 가져오지 못함(2026-10-29 확인). 파일 업로드 방식만 사용함

## 2단계 분석
1. 구조 파악: 화자, 구간별 주제, 타임코드
2. 변수 정의: 핵심 주장, 도구·방법, 수치, 전제 조건
3. 검증: 수치·용어를 원문 대조, 자동 자막 오인식 의심 항목 표시
4. 재정렬: 아래 산출물 양식으로 정리

## 3단계 적용 제안
- 사용자 환경(Claude Code, 업무 스킬, Drive·Gmail·Calendar 연동) 대비 갭 도출
- 즉시 적용안 2~3개 제시: 효과·난이도·리스크 병기
- 적용 형태: CLAUDE.md 규칙 문구, 스킬 초안, 프롬프트 템플릿 중 바로 복사 가능한 형태

## 산출물 양식
핵심 요약 → 구간별 내용 → 현재 활용 방식 대비 갭 → 즉시 적용안 → 리스크·검증 필요 사항
