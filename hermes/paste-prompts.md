# Hermes 붙여넣기 프롬프트 (Windows CLI용, 1회 1개)

> - 각 프롬프트는 한 줄이므로 터미널에 붙여도 중간에 전송되지 않음.
> - 반드시 순서대로 1개씩 붙이고, 결과를 확인한 뒤 다음으로 넘어감.
> - 현재 작업 폴더가 `C:\WINDOWS\system32`이므로 모든 프롬프트에 절대경로를 지정했음.

## 1단계 — 환경 점검 (읽기만 함)
```text
이 PC 환경을 점검해줘. 아무것도 만들거나 바꾸지 말고 결과만 표로 보고해줘. 1) 구글드라이브 데스크톱 동기화 폴더 경로(예: G:\내 드라이브) 2) git 설치 여부와 버전 3) 이미 쓰고 있는 Obsidian 볼트가 있으면 그 경로 4) 현재 연결된 MCP 서버 목록과 Gmail·Google Calendar·카카오 메시지 발송에 쓸 수 있는 도구 유무 5) 텔레그램 게이트웨이 구동 여부와 예약 작업(cron) 실행 가능 여부
```

## 2단계 — 키트 내려받기 + 볼트 생성
```text
https://github.com/denvern75-droid/- 저장소의 claude/keen-wright-rhbdrr 브랜치를 %USERPROFILE%\hermes-kit 폴더에 git clone 해줘. 비공개 저장소라 실패하면 github-auth 스킬로 로그인 절차를 안내해줘. clone이 끝나면 hermes-kit\vault-skeleton 폴더의 모든 하위 폴더와 파일을 1단계에서 확인한 구글드라이브 경로 아래 SecondBrain 폴더로 복사해줘. 같은 이름의 파일이 이미 있으면 덮어쓰지 말고 목록만 보고해줘. 끝나면 SecondBrain 폴더 트리를 보여줘.
```

## 3단계 — 볼트 경로 고정
```text
앞으로 내 세컨드브레인 볼트 경로는 구글드라이브 아래 SecondBrain 폴더(2단계에서 만든 전체 경로)야. 이 경로를 기억하고, obsidian 스킬과 모든 노트 작업의 기본 볼트로 사용해줘. 설정 파일이나 환경변수를 바꿔야 하면 바꾸기 전에 무엇을 어떻게 바꿀지 먼저 보여주고 내 승인을 받아줘.
```

## 4단계 — 상시 지침 등록
```text
%USERPROFILE%\hermes-kit\hermes\standing-instructions.md 파일을 읽고, ```text 코드블록 안의 [세컨드브레인 운영 규칙] 전체를 내 상시 지침으로 메모리에 저장해줘. 규칙 안의 <볼트>는 3단계에서 기억한 SecondBrain 전체 경로로 바꿔서 저장해줘. 저장 후 규칙 1~5번을 한 줄씩 요약해서 보여줘.
```

## 5단계 — 캡처 시험 (텔레그램에서 보냄)
```text
메모 세컨드브레인 연결 테스트입니다
```
- 확인할 것: `SecondBrain\00_Inbox`에 노트가 생기고, 텔레그램으로 "저장됨" 회신이 와야 함.

## 6단계 — 예약 작업 3종 등록 (1개씩)
```text
%USERPROFILE%\hermes-kit\hermes\cron-prompts.md 파일에서 '① 아침 브리핑' 코드블록 내용을 읽고, <볼트>를 SecondBrain 전체 경로로 바꿔 예약 작업으로 등록해줘. 결과는 텔레그램으로 보내도록 해줘. 등록 후 예약 목록을 보여주고, 지금 한 번 시험 실행해줘.
```
```text
%USERPROFILE%\hermes-kit\hermes\cron-prompts.md 파일에서 '② 긴급 알림 점검' 코드블록 내용을 읽고, <볼트>를 SecondBrain 전체 경로로 바꿔 예약 작업으로 등록해줘. 카카오 발송 도구가 없으면 텔레그램 대체 발송 규칙으로 등록하고 그 사실을 알려줘. 등록 후 예약 목록을 보여줘.
```
```text
%USERPROFILE%\hermes-kit\hermes\cron-prompts.md 파일에서 '⑥ 섭외 후속 알림' 코드블록 내용을 읽고, <볼트>를 SecondBrain 전체 경로로 바꿔 예약 작업으로 등록해줘. 결과는 텔레그램으로 보내도록 해줘. 등록 후 전체 예약 목록과 게이트웨이 구동 상태를 보여줘.
```

## 점검 기준
| 단계 | 정상 결과 |
|---|---|
| 1 | 구글드라이브 경로, git 설치 여부가 확인됨 |
| 2 | SecondBrain 아래 폴더 9개와 템플릿 3종이 생성됨 |
| 3~4 | 경로와 규칙 요약이 표시됨 |
| 5 | Inbox 노트 생성 + 텔레그램 회신 |
| 6 | 예약 목록 3건, 게이트웨이 구동 중 |
