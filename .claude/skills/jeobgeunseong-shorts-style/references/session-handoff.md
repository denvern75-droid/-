# 세션 간 넘김 규격 (session handoff)

쇼츠는 컷별로 세션이 분리되므로, 컷 간 일관성은 **매 세션 동일 앵커를 다시 전달**해야만 유지됨.
새 세션 시작 시 아래 절차를 따름.

## 절차
1. `assets/style-anchor.json` 로드 → 값 고정 (임의 변경 금지)
2. 아래 5블록을 세션 프롬프트 서두에 붙여 전달
3. 산출 후 §검증 게이트(SKILL.md §7) 통과 확인

## 넘김 5블록 (필수)

### 1) 스타일 앵커
- `style_lock` 전문을 모든 컷 프롬프트 맨 앞에 고정

### 2) 인물 앵커
- `subject_anchor` 1문장을 전 컷 동일 문구로 사용
- 정면 얼굴 금지 → 뒷모습/오버숄더/손·지팡이·발 클로즈업

### 3) 자막 앵커
- `caption_anchor` 값 준수 (상단 2행, Noto Sans CJK KR Bold, 네이비+앰버, 대비 4.5:1↑)
- 자막 문구 = 내레이션과 완전 일치

### 4) 카메라 앵커
- 컷별 `composition_frames[].move` 사용
- 비교컷(컷 5)은 시설별 동일 앵글·거리·진입방향 강제
- 180도 규칙 유지

### 5) 수치 무결성
- 조사 수치는 확정 자료 대조 후 고정
- 미확정 적합률·등급·달성률 삽입 금지 (규모·시점만으로 서술)

## 넘김 체크리스트
- [ ] style_lock 동일 적용
- [ ] subject_anchor 동일 문구
- [ ] 비교컷 앵글 3패널 동일
- [ ] 자막=내레이션 일치
- [ ] 미확정 수치 0건
- [ ] 광과민 유발 요소 0건
