# 생활 밀착형 접근성 모니터링 지침

## 0. 이 지침의 지위
- 본 지침은 접근성 모니터링 관련 **모든 채팅·코딩·문서 작업의 상위 기준**임
- 개별 산출물 스킬(총평보고서·카드뉴스·쇼츠·설문·촬영 등)과 충돌 시, **판정·근거·수치·조사 독립성** 항목은 본 지침이 우선함
- 산출물 제작 방법 자체는 각 전용 스킬이 담당함(§8 라우팅)
- 영상 등 외부 원료로 지침을 갱신할 때는 §9 절차를 따름

## 1. 목적·원칙
- 목적: 장애인이 **일상적으로 자주 이용하는 생활시설**의 접근성을 이용자 관점에서 진단하고, 근거 기반 개선 권고를 산출함
- 5대 원칙
  1. **경험 기반**: 시설 유무가 아니라 '이용자가 끝까지 이용 가능한가'로 판정함
  2. **근거 중심**: 모든 판정·권고에 법령·지침·현장사실 근거를 병기함
  3. **수치 무결성**: 점수·적합률·등급은 계산 검증 후에만 제시함(§6)
  4. **조사 독립성**: 촬영·홍보·섭외가 조사 판정에 개입하지 않도록 분리함(§7)
  5. **재현 가능성**: 동일 시설을 다른 조사원이 점검해도 같은 판정이 나오도록 기준을 명문화함

## 2. 대상 — '생활 밀착형' 시설 정의
- 이용 빈도가 높고 생활에 직결되는 근린 시설을 우선 대상으로 함
  - 공공: 구청·주민센터·행정복지센터·보건소
  - 의료: 병원·의원·약국
  - 금융·상업: 은행·우체국·마트·편의점
  - 이동·생활: 지하철역·버스정류장·공영주차장·공원
- 선정 기준: ① 이용 빈도 ② 대체 불가성 ③ 민원·요구 다발 여부 ④ 예산·정책 연계 가능성

## 3. 점검 흐름 — 이용 경험 5구간
접근성은 시설 목록이 아니라 **이용 동선 순서**로 점검함.

| 구간 | 점검 관점 | 대표 점검 요소(예시) |
|---|---|---|
| ① 접근 | 시설까지 도달 가능한가 | 보도 점자블록, 횡단보도 음향신호기, 입구 유도동선 |
| ② 진입 | 건물 안으로 들어갈 수 있는가 | 주출입구 경사로·자동문, 점자표지판, 음성유도기 |
| ③ 이동 | 내부에서 목적지까지 이동 가능한가 | 엘리베이터 점자·음성, 촉지도, 바닥 유도블록 연속성 |
| ④ 이용 | 실제 서비스를 이용할 수 있는가 | 키오스크 음성지원, 창구 응대, 서식 접근성, 화장실 |
| ⑤ 탈출·응대 | 비상시·문의시 대응되는가 | 시각경보기·음성안내, 안내데스크 인적지원 체계 |
- 한 구간이라도 **단절되면 전체 이용 실패**로 간주하고 총평에 반영함

## 4. 판정 기준
### 4.1 기본 판정값
- **적합**: 설치 + 규격 충족 + 정상 작동 + 위치·표기 정확
- **부적합**: 설치되어 있으나 규격 미달·위치오류·표기오류 등으로 실사용 불가
- **미설치**: 해당 편의시설이 없음
- **작동불량**: 설치되어 있으나 고장·미작동
- **해당없음(N/A)**: 시설 특성상 적용 대상이 아님(사유 필수 기재)

### 4.2 인적지원 감점 세칙
- 시설(하드웨어) 미비를 **직원 안내로 대체**하는 경우, 접근성 '적합'으로 인정하지 않음
- 인적지원은 **보조 수단**으로만 가점 없이 기록하고, 시설 판정은 시설 기준으로 유지함
- 인적지원 존재를 근거로 부적합 항목을 적합으로 상향하지 않음

### 4.3 판정 시 금지사항
- 확인하지 않은 항목을 추정으로 '적합' 처리 금지
- 근거(사진·현장 진술·계측값) 없는 판정 금지
- 조사원 구어 진술은 **원문 보존**하고 임의 각색 금지

## 5. 근본 원인별 정책 제언(M2 연계)
부적합·미설치 항목의 개선 권고는 **근본 원인**에 따라 문체를 분리함. 사실관계 오류(예: 부적합에 '신설' 권고) 방지가 목적임.

| 근본 원인 | 상태 | 권고 문체 |
|---|---|---|
| 미설치 | 없음 | **신설**(설치) 권고 |
| 작동불량 | 있으나 고장 | **수리·교체** 권고 |
| 위치오류 | 잘못된 위치 | **이전·제거** 권고 |
| 표기오류 | 표기 부정확 | **표기 정정** 권고 |
- 상세 분류·문체는 `m2-root-cause-policy` 스킬을 따름

## 6. 수치 무결성 게이트
- 4단계 절차로만 수치를 산출함
  1. **구조 파악**: 체크리스트 항목·구간·가중치 구조 확인
  2. **변수 정의**: 분자(적합 수)·분모(적용 대상 수, N/A 제외)·감점 규칙 정의
  3. **계산 검증**: 적합률·점수·등급을 재계산으로 교차 검증
  4. **재정렬**: 보고서에 바로 넣을 수 있게 표·등급·요약 정리
- 검증 게이트: 문장 완결성 · 금칙어 · 수치 일치(본문·표·요약 3중 대조) 통과 전 산출 금지

## 7. 조사 독립성·촬영 분리 원칙
- 조사(판정)와 촬영·홍보·섭외는 **역할 분리**함
- 현장 동행 촬영자는 조사 판정에 개입하지 않으며, 조사원과 물리적 거리(예: 5m 규칙)를 유지함
- 초상권은 개별 확인, 촬영·편집은 완전 분리 원칙을 따름(`chwalyeong-seopoe-shotlist`)

## 9. 갱신(업데이트) 절차 — 지침 유지관리
본 지침은 **살아있는 문서**로 관리함. 새 원료(영상·현장 피드백·법령 개정 등)가 확보되면 아래 절차로 갱신함.

1. **원료 수집**: 영상·문서·현장 진술 등 근거를 확보하고 출처를 기록함
2. **차이 식별**: 기존 지침과 달라지는 항목(판정 기준·구간·권고 문체 등)을 특정함
3. **본문 수정**: 해당 절만 최소 수정하고, 다른 절의 표현·수식은 보존함
4. **버전 상향**: 상단 frontmatter의 `version`을 올림(기준: 오·탈자 = PATCH, 항목 추가 = MINOR, 체계 개편 = MAJOR)
5. **이력 기록**: `CHANGELOG.md`에 날짜·버전·변경요지·근거를 개조식으로 추가함
6. **검증**: §6 수치 게이트·금칙어·문장 완결성 통과 확인 후 커밋
