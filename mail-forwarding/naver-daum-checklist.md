# 네이버·다음 → Gmail 자동전달 체크리스트

## 1. 방식 선정 근거
| 방식 | 판정 | 사유 |
|---|---|---|
| **자동전달 (권장)** | 채택 | Hermes에 네이버·다음 비밀번호를 저장하지 않아도 됨. Gmail 하나로 일원화됨 |
| IMAP 직접 연결 | 보류 | 앱 비밀번호를 Hermes 설정에 저장해야 해서 보안 부담이 있음 |
| Gmail '다른 계정 메일 가져오기(POP)' | 비권장 | 2026년부터 Gmail 웹의 해당 기능 지원 종료가 공지됨 |

> 메뉴 이름과 위치는 서비스 개편에 따라 바뀔 수 있음. 아래 경로는 찾을 때 참고용이며 실제 화면에서 확인 필요함.

## 2. 네이버 메일

- [ ] 네이버 메일 → 환경설정 진입
- [ ] '자동전달' 관련 메뉴에서 전달 주소에 Gmail 주소 입력
- [ ] 전달 주소 인증 메일이 오면 Gmail에서 확인 절차 완료
- [ ] **'원본 메일 보관'(전달 후 삭제 안 함)** 선택
- [ ] 전달 범위: 전체 또는 업무 발신자만(조건부 전달이 가능하면 조건부 권장)
- [ ] 테스트: 다른 계정에서 네이버 주소로 메일 발송 → Gmail 도착 및 `출처/네이버` 라벨 확인

## 3. 다음(한메일)

- [ ] 다음 메일 → 환경설정 진입
- [ ] '자동전달' 관련 메뉴에서 Gmail 주소 등록
- [ ] 전달 주소 인증 완료
- [ ] **원본 보관** 선택
- [ ] 테스트: 다음 주소로 메일 발송 → Gmail 도착 및 `출처/다음` 라벨 확인

## 4. 점검 항목 (설정 1주 후)
- [ ] 누락 여부: 네이버·다음 받은편지함 건수와 Gmail 라벨 건수 비교
- [ ] 스팸 오분류: Gmail 스팸함에 전달 메일이 들어갔는지 확인 → 있으면 '스팸 아님' 처리 후 필터에 '스팸으로 보내지 않음' 추가
- [ ] 회신 주소: Gmail에서 답장하면 Gmail 주소로 나가므로, 기관 회신은 원래 계정(네이버·다음)에서 보내는 것을 원칙으로 함

## 5. 리스크
| 리스크 | 대응 |
|---|---|
| 개인정보 메일이 Gmail에도 이중 보관됨 | 조건부 전달 사용 또는 Gmail 필터에서 `브레인` 적재 제외 |
| 전달 지연·누락 | 4번 점검 항목을 월 1회 반복함 |
| 계정 보안 | 네이버·다음 2단계 인증 유지, 전달 주소 외 설정 변경 알림 확인 |
